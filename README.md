Code Review & Vulnerability Analysis
1. Бесконечный цикл при некорректном типе ввода (std::cin)
 Описание проблемы: При запросе пункта меню ввод символа переводит поток std::cin в состояние ошибки (failbit).
 Потенциальные последствия: Зависание программы и бесконечный вывод меню.
 Предлагаемое решение: Сброс флагов ошибки и очистка буфера.
2. Зашитый жесткий путь к файлу (Hardcoded Path)
 Описание проблемы: Путь к файлу указан напрямую: C:\Users\Student\Desktop\protocol.txt
 Потенциальные последствия: Ошибка открытия файла на другом компьютере.
 Предлагаемое решение: Использовать относительный путь.
3. Выход за границы массива (Buffer Overflow)
 Описание проблемы: Индекс articles[index] используется без проверки диапазона.
 Потенциальные последствия: Аварийный сбой программы (Segmentation fault).
 Предлагаемое решение: Проверять индекс перед обращением.
4. Использование «магических чисел»
 Описание проблемы: Числа вроде 30 и 1.5 вписаны напрямую в код.
 Потенциальные последствия: Ошибки при изменении правил расчёта.
 Предлагаемое решение: Вынести параметры в константы.
5. Отсутствие проверки открытия файла
 Описание проблемы: Запись происходит без проверки file.is_open().
 Потенциальные последствия: Потеря данных при отсутствии прав записи.
 Предлагаемое решение: Проверять файл перед записью.
